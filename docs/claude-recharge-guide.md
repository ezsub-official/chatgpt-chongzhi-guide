## Claude 订阅分几种？

Claude 的付费产品主要分两类：

- **订阅（Pro / Max 等）**：按月计费的会员身份，决定你在 Claude 对话产品里的用量与功能。
- **API 用量**：按调用量计费，与订阅是两套不同的计费体系，买订阅不等于买 API 额度。

下单前先确认自己需要的是订阅还是 API，避免买错。本文讲的是订阅充值。
