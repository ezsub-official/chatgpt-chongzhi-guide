# Codex 点数指南｜点数和会员的区别

很多人分不清“Codex 点数”和“Plus/Pro 会员”，买错了才发现用不了。本文先把两者的区别讲清楚，再说谁需要买点数。

## 会员和点数是两回事

| 对比项 | Plus / Pro 会员 | Codex 点数 |
| --- | --- | --- |
| 是什么 | 按月计费的会员身份 | 按量消耗的使用额度 |
| 有效期 | 1 个月，到期需续费 | 长期有效，用完为止 |
| 能否单独使用 | 可以，会员本身包含 Codex 入口 | 不可以，需要账号有生效订阅 |
| 买了点数等于买会员吗 | — | 不等于，点数不包含会员 |
| 适合谁 | 需要 ChatGPT 会员权益的人 | 已有会员、但 Codex 用量不够的人 |

**会员是入场券，点数是入场后的消耗品。**没有会员，点数用不了。有会员但点数用完了，Codex 也跑不动。买之前先判断自己缺的是哪一个。

## 谁需要买 Codex 点数？

- 账号已有生效的 Plus/Pro 订阅；
- 经常用 Codex 跑代码、研究或长任务；
- 会员自带的 Codex 用量在重置前就已耗尽；
- 不想等到下个周期重置，希望马上继续用。

如果你还没有会员，先买会员，不要先买点数。点数不能代替会员。

## 购买前确认清单

1. 账号当前有生效中的 Plus/Pro 订阅（点数需要有生效订阅才能用）。
2. 确认自己缺的是点数额度，而不是会员本身。
3. 下单时核对账号与商品，提交后不能更换账号。
4. 点数长期有效、按量消耗，不同任务消耗的点数不同。

## 常见问题

### 买了 Codex 点数，就能用 Codex 了吗？

不一定。账号的 Plus/Pro 会员有效时，点数才能用。买点数前先确认当前会员是否有效。

### 点数会过期吗？

点数长期有效、按量消耗，不会像会员那样按月到期。但点数不包含会员，会员到期后需要先续会员才能继续用点数。

### 会员到期了，剩下的点数还在吗？

点数本身长期有效。会员到期后，续上会员即可继续使用剩余点数。

### Codex 额度用完了，是买会员还是买点数？

会员到期了，先买会员。会员还在有效期内，只是 Codex 用量耗尽，就买点数。拿不准时，可以先在账号的用量页面确认会员是否有效，再看剩余额度。
